2. Compare and review

  
Check each chunk against its source. OCR, inferred tables, charts and formulas may need correction in the source before approval.

  
  

  
  





  
3. Publish and embed approved chunks

  
  
  
Publish selects the current document version and queues its approved chunks. Index processes one batch. A result of zero means no jobs were due; check the job states for failures or retry delays.

  
  
  
  





  
4. Test evidence search

  
Search returns approved source text and citations. Fake vectors test the workflow; use Cohere to assess semantic matches.

  
  





  
Exact schedule search

  
Validated schedule CSVs become typed rows automatically. Technology, flavor, and date filters use those rows.
