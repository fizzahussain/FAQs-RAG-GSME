# Parsing and chunking release 0.14.6

The MFG-GSME-0002 source manual is 175 pages. Its Docling 30×3 cell-loss warning is on PDF page 2, in the table of contents. Docling dropped 22 of 183 PDF cells from its internal grid and emitted no structured table item for that grid. The prior sparse-page recovery retained the visible contents entries as review-marked prose, but did not expose the lost cells or their positions.

This release captures all 183 raw grid cells, their positions and dropped/matched status as stable evidence diagnostics. The page/table-specific warning reports the grid box and 22 dropped cells. It does not suppress Docling's warning or claim the TOC is a verified structured table. Raw source page 2 and normalized text still need human approval for row/column fidelity.

Source comparison found 30 visible TOC entries. All 30 entry strings survive in review-marked recovered Markdown, but zero were exported as Docling table rows. Of 183 raw PDF cells, 156 carry text rather than dot leaders; 155 match recovered text exactly and the remaining cell differs only by straight versus curly apostrophe (`Moore's`/`Moore’s`). Of the 22 dropped internal cells, 18 contain section/title/page-number text and four contain dot leaders. The PDF-coordinate grid box is `(71, 101, 541, 690)` on page 2; no alternative extractor was promoted because it has not been shown to improve verified row/column fidelity. The cell-by-cell audit is written locally under `validation/` and is excluded from Git.

Local text-fidelity scanning now records suspect Unicode, incomplete tokens and mathematical layouts with page, bounding box, original selectable text, optional independent OCR reading and reason. A bounded OCR pass is diagnostic only: it never replaces source symbols or numbers. Pages with suspect formulas are review-marked. Page 30's `DPPM = (` and page 163's flattened control-chart and yield formulas are therefore not approved formula evidence. The six percentages on page 101 are recorded as unmapped chart labels, with a source box and visual-review status.

Validation JSON links original source SHA-256, normalized Markdown SHA-256, warnings, evidence diagnostics and chunks. Each chunk now carries the source content hash; evidence IDs are stable. Human review decisions live in a separate ledger model. The future-index eligibility gate excludes review-required content without explicit approval and always excludes generic visual-gap placeholders. This release does not implement embeddings or retrieval.

Remaining source work: page 2 TOC grid cells need row/column approval; page 30 and page 163 formulas need verified transcription from the rendered source; page 101's chart relationships need visual review. Docling conversion of this manual is CPU-intensive and OCR diagnostics add bounded extra work.

On this Windows environment, the clean full Docling validation took 595.199 seconds and produced 1,817 chunks; the prior saved 0.14.5 run took 465.070 seconds. These runs were not controlled benchmarks, so their 130-second difference cannot be attributed solely to this release. The isolated fidelity scan took 5.443 seconds, finding 73 suspect regions on 22 pages and retaining 11 OCR alternatives. The full 117-test suite passed. The Docling warning remains visible.
